# My Notes and Solutions

Store personal learning notes, exercise solutions, experiments, and reusable
artifacts here. Track overall progress in [learning.md](../learning.md).

Create one folder per lesson or topic, for example
`solution/01-python-basics/`. Use the curriculum's phase and lesson slugs when
useful to keep work easy to find.

Each folder can contain:

- `notes.md`: concepts in my own words, examples, questions, and takeaways.
- `main.py` (or another language): my implementation or exercise solution.
- `tests/`: checks for my implementation.
- `outputs/`: artifacts produced while learning.

Link back to the original lesson in the notes, and record how to run the code
and what was verified. Keep personal work here without editing the curriculum's
reference solutions.
